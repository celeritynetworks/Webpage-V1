# Celerity Networks Ltd website

A responsive React + Vite website starter using Celerity Networks' supplied official logo.

## Run locally

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Install packages (PowerShell users can use the `.cmd` wrapper):

   ```powershell
   npm.cmd install
   ```

4. Start the development server:

   ```powershell
   npm.cmd run dev
   ```

5. Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Production build

```powershell
npm.cmd run build
```

The deployable static site is written to `dist/`.

## Before publishing

- Confirm the displayed phone number, address, email, course descriptions and service list.
- Add/confirm social profile links and any privacy policy needed for enquiry forms.
- Purchase a domain only after checking availability and choosing a registrar.
- This initial version sends enquiries through WhatsApp/email links. It does not yet store form submissions or process payments.
